# じゃんけんバトル

## デモ
https://ando-nanako.github.io/janken/

## 紹介と使い方
コンピュータ（ニワトリ）とおたがいの💗を削り合うじゃんけんです。

1. グー・チョキ・パーのボタンを押す
2. 勝ったら相手の💗が1つ減り、負けたら自分の💗が1つ減る（あいこは何も起きない）
3. 先に相手の💗（3つ）を0にしたほうが勝ち。「もう一回」で最初から遊べる

## 工夫した点
- 「じゃん…けん…」と少し待ってから結果を出し、ドキドキ感を出した（setTimeout）
- 勝ち・負け・あいこで、ニワトリのセリフと文字の色を変えた
- 勝ち負けの判定を1つの関数（judge）にまとめた

## 苦戦した点
- 結果が出る前にボタンを連打されないようにする処理（playing の変数）

## 使った技術
HTML / CSS / JavaScript / jQuery
