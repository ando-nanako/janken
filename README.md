## ⑤工夫した点・こだわった点
- どこから手をつけていけば良いのかがわからなかったため、GitHubのissueにclaudeから手順書を作成してもらってから進めました。
- 今回はcommand+/でコメントでメモをして、後で読み返しても理解できるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 処理を `});` の外に書いてしまい、クリックしても動かなかったり、`n is not defined` というエラーが出たりしました。「クリックしたときに実行したい処理は、すべて `function(){ }` の中に書く」「const で作った変数は、作った `{ }` の中でしか使えない」ことを理解できました。
- `#judgment` や `#pc_hands` が、HTMLのどの部分を指しているのか最初はわからず、idとJavaScriptのつながりを理解するのに時間がかかりました。
- 今回は最低限の機能のみ作成したため、次回授業までにUIを整えたいと思います。
