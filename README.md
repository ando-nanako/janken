# ①課題名
じゃんけんバトル

## ②課題内容（どんな作品か）
- コンピュータ（ニワトリ）とおたがいの💗（HP）を削り合うじゃんけんアプリ
- 勝ったら相手の💗が1つ減り、負けたら自分の💗が1つ減る。あいこは何も起きない
- 先に相手の💗（3つ）を0にしたほうが勝ち。「もう一回」で最初から遊べる
- HTML / CSS / JavaScript（jQuery）で作成

## ③アプリのデプロイURL
https://ando-nanako.github.io/janken/

## ④アプリのログイン用IDまたはPassword（ある場合）
- なし

## ⑤工夫した点・こだわった点
- 「じゃん…けん…」と少し待ってから結果を出し、ドキドキ感を出した（setTimeout）
- 勝ち・負け・あいこで、ニワトリのセリフと文字の色を変えた
- 勝ち負けの判定を1つの関数（judge）にまとめた

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 結果が出る前にボタンを連打されないようにする処理（playing の変数）
- 次回は連勝数の表示や、記録の保存に挑戦したい
